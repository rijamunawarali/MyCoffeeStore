# MyCoffeeStore - Brewed Coffee House

A modern, fully responsive coffee store web application built using HTML, Bootstrap 5, CSS, and custom media queries. This project features interactive modals, dynamic cards, tooltips, and a clean user-centric layout.

## Features

- **Responsive Header & Navigation:** Sticky-top navbar with quick action buttons ("Call Us" and "Chat with Us").
- **Interactive Modals:** 
  - *Explore Our Menu Modal:* Showcases various coffee items dynamically in Bootstrap cards.
  - *Order Now Modal:* Interactive form allowing users to select their favorite coffee variants, quantity, and input personal details.
- **Visual Highlights & Features:** Highlights section showcasing fresh roasted beans, aroma, and quality badges.
- **Embedded Location:** Integrated Google Maps location for easy store tracking.
- **Customer Counters & Ratings:** Clean statistics section displaying customer satisfaction and ratings.
- **Comprehensive Footer:** Includes quick links, menu highlights, contact details, and social media handles.
